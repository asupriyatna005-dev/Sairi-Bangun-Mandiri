# Sairi Bangun Mandiri — Website
Website statis responsive menggunakan HTML, CSS, JavaScript, dan foto proyek asli.

## File
- `index.html` = semua teks/konten website
- `style.css` = desain/layout/responsive
- `script.js` = menu mobile dan form WhatsApp
- `images/` = foto proyek

## Sebelum online
Ganti nomor WhatsApp `6281234567890`, email, area layanan, dan teks placeholder di `index.html`. Nomor WhatsApp pada form juga ada di `script.js`.

## GitHub Pages
Buat repository baru → upload semua file/folder ini → Settings → Pages → Deploy from branch → pilih `main` dan `/ (root)` → Save.


## Logo perusahaan
Logo pada `images/logo-sbm.png` menggunakan logo asli yang Anda upload.
